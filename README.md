# Chrono Dungeon

시간을 멈춰 탄막을 읽고, 움직이며 돌파하는 탑다운 픽셀 액션 로그라이트 게임입니다. 브라우저에서 바로 실행할 수 있는 단일 HTML 파일로 제작했습니다.

## 어떤 게임인가요?

플레이어는 시간 마법사가 되어 던전의 방마다 등장하는 적과 탄환을 상대합니다. 가만히 있으면 크로노 게이지를 소모하며 적과 탄환의 시간이 느려집니다. 그 사이 안전한 경로를 살핀 뒤 이동, 대시, 공격으로 방을 클리어합니다.

적을 처치해 경험치와 골드를 얻고, 레벨업 때 강화 카드를 선택합니다. 한 번의 도전이 끝나면 모은 골드로 영구 강화를 구매해 다음 도전에 활용할 수 있습니다.

**핵심 흐름:** 멈춰서 읽기 → 이동과 대시로 피하기 → 조준해서 공격하기 → 보상으로 성장하기

## 실행 방법

[`index.html`](./index.html)을 브라우저에서 열고 **시작**을 누르면 됩니다. 별도 설치나 서버가 필요하지 않습니다.

## 조작

| 입력 | 동작 |
| --- | --- |
| `W` `A` `S` `D` | 이동 |
| 마우스 이동 | 조준 |
| 마우스 클릭 | 공격 |
| `Space` | 대시 |
| `Esc` | 일시정지 메뉴 |

모바일에서는 화면의 가상 스틱과 공격 버튼을 사용할 수 있습니다. 영구 강화 데이터는 현재 브라우저의 로컬 저장소에 저장되므로, 브라우저 데이터를 지우거나 다른 기기로 옮기면 이어지지 않습니다.
